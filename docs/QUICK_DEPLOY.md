# Quick EC2 Deployment

Since Docker and Docker Compose are already installed on your EC2 instance, here are the minimal steps:


## 1. Login to EC2 and Clone the Project

```bash
ssh -i your-key.pem ec2-user@your-ec2-host

git clone https://github.com/Slightly-Techie/discount-ecommerce-api.git
cd discount-ecommerce-api
```

## 2. Generate SSL Certificates

```bash
# Make the script executable
chmod +x generate-ssl.sh

# Run the script with your domain
./generate-ssl.sh api.grottomore.com admin@api.grottomore.com
```

If the certificates were generated by Certbot into `ssl/live/api.grottomore.com/`, copy them into the nginx-compatible file names:

```bash
mkdir -p ssl
cp ssl/live/api.grottomore.com/fullchain.pem ssl/cert.pem
cp ssl/live/api.grottomore.com/privkey.pem ssl/key.pem
chmod 600 ssl/key.pem
chmod 644 ssl/cert.pem
```

## 3. Initialize Database (first deploy + every release)

```bash
# Start database service
docker compose up -d db

# Apply schema migrations
docker compose run --rm web python manage.py migrate --noinput

# Collect static files
docker compose run --rm web python manage.py collectstatic --noinput

# Seed country data (idempotent)
docker compose run --rm web python manage.py add_countries
```

## 4. Start Application

```bash
docker compose up -d --build --remove-orphans
```

## 5. Create Superuser

```bash
docker compose exec web python manage.py createsuperuser
```

## 6. Monitor Application

```bash
./monitor.sh
```

## AWS Security Group

Make sure these ports are open:
- HTTP (80) - 0.0.0.0/0
- HTTPS (443) - 0.0.0.0/0
- SSH (22) - Your IP only

## Access Your Application

- **Main App**: `https://your-domain.com/`
- **Admin**: `https://your-domain.com/admin/`
- **API**: `https://your-domain.com/api/`
- **Swagger**: `https://your-domain.com/swagger/`

That's it! Your Django application is now deployed with SSL.
